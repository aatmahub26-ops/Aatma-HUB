# **App Name**: Aatma HUB

## Core Features:

- Esports Marketplace: Comprehensive gaming catalog supporting user ID and server inputs for popular titles like MLBB and PUBG.
- Managed Digital Wallet: Firestore-powered ledger system tracking balances, top-up requests, and transactional debit/credit history.
- Multi-Role Dashboard: Separate interfaces for gamers to track orders and admins to manage inventory, payments, and users.
- Gamified Referral System: Unique referral code generation for users to track earnings and invite-driven commission growth.
- Smart Order Tracking: Real-time order status updates including pending, processing, completed, and failed states.
- AI Support Tool: A tool that uses generative AI to provide instant assistance with common order issues and game-specific ID instructions.
- Firebase Unified Auth: Secure account lifecycle management with protected dashboard routing for admin and customer views.

## Style Guidelines:

- Primary Color: Electric Violet (#9E66FF) to evoke high-energy gaming aesthetics and professional esports vibes.
- Background Color: Midnight Abyss (#130F1A), a deeply desaturated version of the primary hue for a premium dark mode feel.
- Accent Color: Kinetic Indigo (#6B7CFF) used for highlighting call-to-action buttons and successful transaction states.
- Headline Font: 'Space Grotesk' (sans-serif) for a modern, tech-forward, and machined gaming look.
- Body Font: 'Inter' (sans-serif) for high legibility in dense transactional dashboards and wallet histories.
- Esports-grade mobile-first grid system featuring edge-to-edge product cards and high-density information displays.
- Neon-glow transition effects and progressive loading skeletons to maintain a high-performance visual experience.
